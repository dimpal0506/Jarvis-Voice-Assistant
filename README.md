# Jarvis Voice Assistant

Jarvis is a Python-powered personal voice assistant that can perform tasks such as answering questions, opening websites, searching Wikipedia, playing YouTube videos, sending WhatsApp messages, and more.  
It uses **Speech Recognition**, **Text-to-Speech (TTS)**, and API integrations for smart responses.

## ✨ Features
- 🎙 Real-time voice command recognition
- 🗣 Natural-sounding voice replies
- 🔍 Wikipedia search
- 📺 YouTube automation
- 🌐 Open websites
- 💬 ChatGPT integration
- 📅 Date & time updates
- 🎵 Play songs directly from YouTube
- 📱 Send WhatsApp messages
